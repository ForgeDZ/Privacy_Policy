1. About MultiLink Extractor

MultiLink Extractor is a browser extension for Chromium-based browsers and Firefox. It collects the hyperlinks inside a text selection on a web page and turns file-hosting page links for fuckingfast.co, datanodes.to and filekeeper.net into the direct download URLs behind them.

Developer: Forge DZ

2. Data Collection and Sharing

MultiLink Extractor does not collect, transmit, or share user data. Forge DZ operates no server for this extension and receives no information from it.

  • No accounts, registration, or login.
  • No analytics, telemetry, tracking, advertising, or crash reporting.
  • No selling, renting, or sharing of user data with third parties.
  • No collection of browsing history, and no synchronization of any data to a Forge DZ service.
  • No remote code: every script the extension runs is contained in its own package.

3. Information Stored in the Browser

The extension uses the browser's local extension storage so its own page keeps working between visits:

  • Link list: the URLs in the extension's input box, saved as you type.
  • Results: the rows produced by the last extraction run — original URL, status, host, file name, file size and the direct URL — so they are still there if the page is reopened.
  • Settings: the theme, the automatic start for direct links, and the request details the extraction engine uses for the three supported hosts.
  • Hand-off marker: a short-lived flag that lets the extractor page continue a run that was started from the toolbar popup.

All of this stays inside your browser profile. It is never uploaded to Forge DZ. It is not encrypted beyond the browser's own protection of its profile directory.

4. Page Content and Selected Links

Reading a page happens only when you ask for it. When you right-click inside a selection and choose Copy All Links or Send to MultiLink Extractor, the extension reads the links inside that selection on that page and nothing more. With Copy All Links the text goes straight to your clipboard. With Send to MultiLink Extractor the links are passed internally to the extension's own page.

On fuckingfast.co, datanodes.to and filekeeper.net only, a content script also reads the file page — its download form, file name, file size, and any Cloudflare Turnstile challenge state — so the extension can follow the site's own download flow. It is not injected into any other website.

The pages you visit, the text you select and the results are not sent to Forge DZ or to any advertising or analytics provider.

5. Cookies and File-Host Requests

To fetch a direct download link, the extension sends requests to the same host that hosts the file. Those requests are made on your behalf, as your session:

  • The extension reads the cookies that already exist for the exact file-host URL involved, and sends them back only to that same host.
  • Cookies are never sent to Forge DZ, and no cookie is read for any other website.
  • For filekeeper.net, the extension reads the redirect target of its own request instead of following it, which is what the webRequest permission is used for.

Requests go to fuckingfast.co, datanodes.to and filekeeper.net — no other host is contacted. Those websites operate independently of Forge DZ, and their own privacy practices, logging and terms apply to your use of them. Links for any other site are reported as Unsupported and are not requested.

If a host presents a Cloudflare Turnstile check, the page is left open for you to complete by hand. The challenge is served and verified by that website and Cloudflare, not by the extension.

6. Clipboard

The extension writes to the clipboard only when you ask it to — through Copy All Links, the copy button next to a result, or copying the result list. It does not read clipboard contents and does not copy anything on its own.

7. Permissions Used

  • contextMenus: adds the two right-click commands.
  • activeTab and scripting: read the selection on the current page only after you choose one of those commands.
  • clipboardWrite: copies links or results when you ask.
  • storage: keeps the input, results and settings in your browser.
  • cookies: sends a file host its own cookies with the extension's request to it.
  • tabs: opens, finds and closes the extension's own extractor page.
  • webRequest: reads the redirect target for filekeeper.net.
  • Host access to fuckingfast.co, datanodes.to and filekeeper.net: the only websites the extension contacts.

8. Data Retention and Deletion

Because nothing is sent to a server, there is no remote copy to delete.

  • Results can be cleared from the extension's page with its clear control.
  • The link list can be emptied by clearing the input box.
  • All extension data — input, results and settings — is removed by uninstalling the extension, or by clearing its site/extension data in the browser's settings.

9. Incognito Windows

If you allow the extension in private or incognito windows, it can be used there too. Its stored input, results and settings are shared with the extension's normal profile storage; pages you visit while using it are still not reported to Forge DZ.

10. Children's Privacy

MultiLink Extractor is a general-purpose utility for collecting links and is not directed at children. It collects no personal information from any user, including children.
