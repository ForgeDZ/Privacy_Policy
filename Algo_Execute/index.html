1. About Algo Execute

Algo Execute is an Android programming environment that combines a code editor, an interpreter for the app's programming language, and a built-in language reference. It provides the tools needed to write, edit, and execute programs.

Developer: Forge DZ

2. Offline Operation

Algo Execute operates entirely on the device. Programs can be written, edited, and executed without an internet connection. The application does not rely on cloud services or remote processing.

3. Data Collection and Sharing

Algo Execute does not collect, transmit, or share user data. It does not send user-created programs, typed input, execution results, saved programs, editor sessions, or other content to Forge DZ or an external service. The application does not have accounts, registration, or login.

Information saved locally remains on the device; it is not collected for external use or shared with third parties.

The application does not use tracking, analytics, telemetry, or crash reporting, and it has no online AI features.

4. Information Stored on the Device

The application stores the following information locally so its features can work:

  • Saved programs and collections: Program source code, program and collection names, collection details, and modification times are kept in the app's private storage until deleted by the user.
  • Editor session: The application saves the current editor session, including source code that has not been saved as a program, along with relevant editor state. This session can be restored after the app restarts.
  • Appearance preferences: The selected theme and editor font size are saved on the device.
  • Sequential Files: Files created through the app's file-handling features are stored in the app's private storage and remain there until deleted using the Delete operation in the app's language.
  • Console: Console input and execution output are processed locally. The console does not save a persistent transcript or runtime input history.

5. User Content and Program Execution

The interpreter processes programs locally on the device. Program execution does not use an online compiler or remote service.

6. Clipboard and Keyboard

Clipboard and Copy AI Prompt

In the Syntax Reference, “Copy AI Prompt” copies static language-reference text to the Android clipboard. It does not contact an AI service or automatically copy source code from the editor.

Users can also initiate standard Android copy, cut, and paste actions in the editor. Text pasted into another application is handled according to that application's own practices.

Android Keyboard and Text Input

Text entry uses the keyboard selected on Android. Algo Execute does not control the keyboard provider. Any independent handling of typed text by a third-party keyboard is governed by that provider's practices.

7. Data Retention and Deletion

  • Users can delete saved programs and collections through the app's collection management interface.
  • Sequential files can be deleted with the Delete operation in the app's language.
  • The editor's Reset function replaces the current editor session with the starter program. It does not erase all app information.
  • Users can remove locally stored app data by clearing Algo Execute's storage in Android system settings.
  • Uninstalling the application normally removes its private data, subject to Android and device-manufacturer behavior.

The application creates no user accounts and has no account-deletion feature or in-app erase-all-data function.

8. Data Security and Device Backups

Local Data Storage and Security

Saved programs, files, and application settings are stored in the app's private storage on the user's device. The app does not apply additional encryption to this locally stored information.

Android Backups and Device Transfers

Standard Android app backup is disabled for Algo Execute. However, some device manufacturers may support transferring application data directly between devices. This behavior depends on the device and its system configuration.

9. Children's Privacy

Algo Execute is a programming application intended for users of all ages, including children. Its built-in content focuses on programming and learning, providing tools for code editing, program execution, and reference materials for the app's language.

The application's built-in content contains no advertisements, violent content, or sexually explicit material. It is not designed to be age-inappropriate.

Users can create and execute their own programs. The content and behavior of user-created programs depend on the code entered by their creators.

10. Changes to This Privacy Policy

Forge DZ will update this policy if the application's features or privacy practices change. The latest revision date appears below the Privacy Policy heading.
